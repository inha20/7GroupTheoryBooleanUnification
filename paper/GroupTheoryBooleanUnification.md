**A Group-Theoretic Unified Classification of Boolean Function Spaces on Karnaugh Maps**

## 초록 / Abstract

본 논문은 4변수 카르노맵에서 발생하는 부울 함수 패턴의 군론적 통합 분류를 제시한다.
선행 연구 4편(Paper 1–3, 6)에서 독립적으로 발견된 결과들을 하나의 수학적 언어—대칭군 S₄와 이면체군 D₄—로 통합하여, 변수 배치 동치류(24→3), 대칭 부울 함수의 Hamming weight 레이어 구조, 변수 재배열 불변성, XOR/AND/NOT 게이트 생성 공간의 궤도 분류를 하나의 일관된 프레임워크로 서술한다.

주요 결과는 다음과 같다:
- 4변수 카르노맵의 변수 배치는 D₄ 작용 하에 정확히 **3개의 동치류** (AB/CD, AC/BD, AD/BC)로 분류된다.
- 대칭 부울 함수 공간은 **Hamming weight 레이어** (층 0–4)로 완전히 기술되며, 총 $2^5 = 32$개의 완전대칭함수가 존재한다.
- 변수 재배열(S₄ 치환) 하의 동치류 분류는 Burnside 보조정리에 의해 검증된다.
- S₄ 작용 하의 게이트 공간: Space(XOR)→10궤도, Space(AND)→30궤도, Space(NOT)→32궤도.

**핵심어:** 부울 함수, 카르노맵, 이면체군 D₄, 대칭군 S₄, Burnside 보조정리, 동치류, 변수 재배열, Hamming weight

## 2. 변수 배치 동치류: D₄ 이면체군 분석

### 2.1 카르노맵 변수 배치의 수학적 구조

4변수 카르노맵은 변수 {A, B, C, D}를 행(2변수)과 열(2변수)에 배치하여 구성한다. 가능한 배치의 수는 다음과 같다:

$$\binom{4}{2} \times 2! \times 2! = 6 \times 2 \times 2 = 24$$

그러나 이 24개가 모두 본질적으로 다른 배치인가? 우리는 **아니다**라고 답한다.

### 2.2 동치 관계의 정의

두 배치 $P_1$과 $P_2$는 다음 세 변환 중 하나에 의해 연결될 때 **동치**라고 정의한다:

1. **행 변수 교환**: $XY/ZW \sim YX/ZW$ (행 내 변수 순서 교환)
2. **열 변수 교환**: $XY/ZW \sim XY/WZ$ (열 내 변수 순서 교환)
3. **행-열 전치**: $XY/ZW \sim ZW/XY$ (행과 열 전체 교환, y=−x 대각선 대칭)

이 세 생성원은 이면체군 D₄를 생성한다.

### 2.3 주요 정리

**정리 2.1** (배치 동치류 완전 분류):  
4변수 카르노맵 변수 배치 24개는 D₄ 작용 하에 정확히 **3개의 동치류**로 분류된다:

$$\mathcal{E}_1 = [AB/CD], \quad \mathcal{E}_2 = [AC/BD], \quad \mathcal{E}_3 = [AD/BC]$$

**증명 개요:**

1단계: 행 변수 교환으로 24→12개로 축약 (배치별 행 내 중복 제거)
2단계: 열 변수 교환으로 12→6개로 축약
3단계: 행-열 전치로 6→3개로 축약 ($\{AB/CD \sim CD/AB\}$, $\{AC/BD \sim BD/AC\}$, $\{AD/BC \sim BC/AD\}$)

따라서:

$$|\mathcal{E}| = \frac{\binom{4}{2}}{2} = \frac{6}{2} = 3 \quad \square$$

### 2.4 독립 동치류 대표원

| 동치류 | 대표 배치 | 포함되는 배치들 |
|--------|----------|----------------|
| $\mathcal{E}_1$ | AB/CD | AB/CD, BA/CD, AB/DC, BA/DC, CD/AB, DC/AB, CD/BA, DC/BA |
| $\mathcal{E}_2$ | AC/BD | AC/BD, CA/BD, AC/DB, CA/DB, BD/AC, DB/AC, BD/CA, DB/CA |
| $\mathcal{E}_3$ | AD/BC | AD/BC, DA/BC, AD/CB, DA/CB, BC/AD, CB/AD, BC/DA, CB/DA |

## 3. 대칭 부울 함수: Hamming Weight 레이어 구조

### 3.1 정의

**정의 3.1**: 4변수 부울 함수 $f: \{0,1\}^4 \to \{0,1\}$이 **완전 대칭**이라 함은, 임의의 치환 $\sigma \in S_4$에 대해

$$f(x_1, x_2, x_3, x_4) = f(x_{\sigma(1)}, x_{\sigma(2)}, x_{\sigma(3)}, x_{\sigma(4)})$$

가 성립하는 것이다.

### 3.2 Hamming Weight 레이어

4변수 입력 벡터를 Hamming weight(입력 중 1의 개수)에 따라 분류하면:

| Layer | Hamming Weight | 입력 수 | 예시 |
|-------|---------------|---------|------|
| $L_0$ | 0 | 1 | 0000 |
| $L_1$ | 1 | 4 | 0001, 0010, 0100, 1000 |
| $L_2$ | 2 | 6 | 0011, 0101, 0110, ... |
| $L_3$ | 3 | 4 | 0111, 1011, 1101, 1110 |
| $L_4$ | 4 | 1 | 1111 |

**정리 3.1**: 완전 대칭 함수는 Hamming weight만으로 완전히 결정된다. 즉, 각 Layer에 대해 0 또는 1의 출력값을 독립적으로 선택할 수 있으므로, 완전 대칭 함수의 총 수는:

$$2^5 = 32$$

### 3.3 주요 완전 대칭 함수 예시

| 함수 | 설명 | Layer 출력 패턴 (L₀L₁L₂L₃L₄) |
|------|------|-------------------------------|
| 상수 0 | 항등 거짓 | 00000 |
| 상수 1 | 항등 참 | 11111 |
| $A \oplus B \oplus C \oplus D$ | 4-XOR | 01010 |
| $\text{Majority}(A,B,C,D)$ | 과반수 | 00011 |
| $A \cdot B \cdot C \cdot D$ | 4-AND | 00001 |
| $A + B + C + D$ | 4-OR | 01111 |

## 4. 변수 재배열 불변성

### 4.1 S₄ 작용 하의 동치류

대칭군 S₄는 4변수 {A,B,C,D}의 모든 치환을 포함하며 |S₄| = 24이다.

**정의 4.1**: 두 함수 $f, g \in \mathcal{F}_4$가 **변수 재배열 동치**라 함은, 어떤 $\sigma \in S_4$가 존재하여

$$g(x_1,x_2,x_3,x_4) = f(x_{\sigma(1)}, x_{\sigma(2)}, x_{\sigma(3)}, x_{\sigma(4)})$$

가 성립하는 것이다.

### 4.2 Burnside 보조정리에 의한 검증

S₄ 작용에 의한 $\mathcal{F}_4$ 전체의 궤도 수는 Burnside 보조정리에 의해:

$$|\mathcal{F}_4 / S_4| = \frac{1}{|S_4|} \sum_{\sigma \in S_4} |\text{Fix}(\sigma)|$$

여기서 $|\text{Fix}(\sigma)|$는 $\sigma$에 의해 불변인 함수의 수이다.

## 5. 게이트 생성 공간의 S₄ 궤도 분류

### 5.1 주요 공간 정의

| 공간 | 생성 게이트 | 원소 수 | 수학적 구조 |
|------|-----------|---------|------------|
| Space(XOR) | XOR | 32 | 아핀 함수 공간 (벡터 공간 위 F₂) |
| Space(AND) | AND, NOT | 168 | 단조 부울 함수 |
| Space(NOT) | NOT, AND, OR | 256 | 자기쌍대 부울 함수 |

### 5.2 궤도 분류 결과

**정리 5.1**: S₄ 작용 하의 주요 공간 궤도 수:
- Space(XOR): **10궤도** (Burnside 검증 완료)
- Space(AND): **30궤도** (Burnside 검증 완료)
- Space(NOT): **32궤도** (Burnside 검증 완료)

**정리 5.2** (고정점 비존재): Space(NOT)에는 S₄ 작용 하에 고정점이 존재하지 않는다.

*증명*: 자기쌍대 함수 $f$가 S₄-고정점이려면 임의의 $\sigma$에 대해 $f \circ \sigma = f$이어야 하므로, $f$는 완전 대칭이고 동시에 자기쌍대이어야 한다. 하지만 완전 대칭 자기쌍대 함수는 $f = \neg f$를 만족해야 하므로 존재하지 않는다. $\square$

## 6. 통합: 단일 수학적 프레임워크

### 6.1 계층 구조

$$\text{D}_4 \text{ 변수배치 동치류} \xrightarrow{\text{포함}} S_4 \text{ 재배열 동치류} \xrightarrow{\text{포함}} \text{게이트 공간 궤도}$$

- D₄는 S₄의 부분군으로 볼 수 있다 (카르노맵 행-열 대칭에 해당).
- 변수 배치 동치류 3개는 S₄ 궤도의 coarse refinement이다.
- 완전 대칭 함수는 S₄ 작용 하의 크기 1 궤도와 정확히 대응한다.

### 6.2 요약 다이어그램

```
전체 F₄ (65,536개 함수)
├── Space(XOR): 32개 → S₄ 작용 → 10 궤도
├── Space(AND): 168개 → S₄ 작용 → 30 궤도
├── Space(NOT): 256개 → S₄ 작용 → 32 궤도
│
└── 완전 대칭 함수: 32개 (Hamming weight 5-bit encoding)
    └── 카르노맵 변수 배치 동치류: 3개 (D₄ 작용)
```

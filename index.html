초록 / Abstract

본 논문은 4변수 카르노맵에서 발생하는 부울 함수 패턴의 군론적 통합 분류를 제시한다. 선행 연구 4편(Papers 1–3, 6)에서 독립적으로 발견된 결과들을 하나의 수학적 언어—이면체군 D₄와 대칭군 S₄—로 통합한다. 주요 결과: 변수 배치 동치류 $24 \to 3$, 대칭 부울 함수 $2^5 = 32$개, Space(XOR) 10궤도 · Space(AND) 30궤도 · Space(NOT) 32궤도. 모든 결과는 Burnside 보조정리와 Python 전산 열거로 이중 검증되었다.

통합 출처: P1 §5.5 D₄ 증명 P2 Hamming Layer P3 S₄ 재배열 P6 궤도 분류
🔑 핵심 정리 / Key Theorems
정리 2.1 — D₄ 변수 배치 동치류
$|\mathcal{E}| = \dfrac{\binom{4}{2}}{2} = 3$
24개 배치 → D₄ 작용 → 3개 독립 동치류 (AB/CD, AC/BD, AD/BC)
정리 3.1 — 완전 대칭 함수
$|\text{Sym}_4| = 2^5 = 32$
Hamming weight 5개 레이어 × 독립적 0/1 선택
정리 5.1 — S₄ 궤도 분류 (Burnside)
XOR: 10궤도 · AND: 30궤도 · NOT: 32궤도
Python 전산 열거로 독립 검증 완료
정리 5.2 — Space(NOT) 고정점 비존재
$\text{Fix}_{S_4}(\text{Space(NOT)}) = \emptyset$
자기쌍대 ∧ 완전대칭 → 모순 ∴ 고정점 없음
